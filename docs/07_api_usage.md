# API Usage

## Provider
**Dog API**: [https://dog.ceo/dog-api/](https://dog.ceo/dog-api/)

## Endpoints
### Get Random Images
- **URL**: `https://dog.ceo/api/breeds/image/random/20`
- **Method**: GET
- **Response Format**: JSON
- **Sample Response**:
```json
{
    "message": [
        "[https://images.dog.ceo/breeds/terrier-irish/n02093991_403.jpg](https://images.dog.ceo/breeds/terrier-irish/n02093991_403.jpg)",
        "[https://images.dog.ceo/breeds/mexicanhairless/n02113978_3151.jpg](https://images.dog.ceo/breeds/mexicanhairless/n02113978_3151.jpg)"
    ],
    "status": "success"
}
