# Project Overview: WoofWoof

## Purpose
WoofWoof is an Android application designed for users to discover and browse random images of various dog breeds.

## Target Audience
- Android development students.
- Users looking for a quick "cute dog" photo.

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: XML Views (Material Components)
- **Networking**: Retrofit / OkHttp
- **Image Loading**: Glide or Coil
- **Architecture**: MVVM (Model-View-ViewModel)
