# WoofWoof - Dog Gallery App

WoofWoof is a simple Android app that fetches and displays random dog images using the Dog API. This project was developed as part of Tutorial 2, Part 3, focusing on AI-assisted development.

## Features
- Browse 20 random dogs.
- Pull-to-refresh for new images.
- Built with MVVM and Retrofit.

## How to Run
1. Clone the repository.
2. Open in AntiGravity IDE / Android Studio.
3. Sync Gradle and run on an emulator or device.
