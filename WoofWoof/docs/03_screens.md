# Screens and UI

## MainActivity
The primary screen of the application.

### Components
1. **Toolbar**: Displays the app name "WoofWoof".
2. **SwipeRefreshLayout**: Wraps the content to allow users to pull down to refresh the list.
3. **RecyclerView**: A Grid layout (2 columns) displaying images.
4. **ProgressBar**: Shown while the initial list is loading.
5. **Empty/Error State**: A TextView and "Retry" button shown if loading fails.

### UI Style
- **Theme**: Material3 (Light/Dark support).
- **Primary Color**: Paw-print Orange or Dog-collar Blue.
